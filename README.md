# MANOO Tech | Official Engineering Studio Website

Official website for **MANOO Tech** — Software development and mobile engineering studio specializing in high-performance native Android applications and modern web platforms.

## 🚀 Live Products
- **MuziPlay**: Advanced offline music player, 32-bit audio engine, dynamic synced lyrics, and lossless DSP equalizer. (`com.aistudio.muziplay.xnxfyx`)
- **Brixy**: Minimalist block puzzle game with 120 FPS fluid physics, haptics, and clean aesthetics. (`com.aistudio.brixy.kwxyzq`)

- **Bilingual Support (i18n)**: English (LTR) and Arabic (RTL) with seamless real-time toggle.
- **Dual Themes**: Dark Mode and Platinum Light Mode.
- **Interactive UI**: Interactive particle canvas, device frame mockups with live screenshot switching, responsive mobile navigation, and contact forms.
- **Zero Framework Bloat**: Pure, ultra-fast Vanilla HTML5, CSS3, and JavaScript.
